# Проектная работа: Рефакторинг API-хелпера

## Описание

Это стартовый репозиторий для проектной работы спринта. Здесь лежит процедурный код для работы с API курьеров и тесты к нему. Ваша задача — выполнить рефакторинг с использованием ООП и оформить результат через Pull Request.

## Что внутри

| Файл | Описание |
|------|----------|
| `helpers.py` | Старые процедурные функции для работы с API |
| `api_client.py` | Пустой файл — сюда вы напишете класс `CourierAPIClient` |
| `test_couriers.py` | Тесты, которые сейчас вызывают старые функции. Их нужно переписать под класс |
| `fake_api.py` | Имитация API (этот файл изменять не нужно) |
| `conftest.py` | Фикстура для запуска `fake_api` (этот файл изменять не нужно) |
| `.env.example` | Шаблон переменных окружения |
| `requirements.txt` | Зависимости проекта |

## Быстрый старт

```bash
# Клонируем репозиторий
git clone <ссылка>
cd <папка>

# Настраиваем окружение
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env

# Запускаем тесты — должны быть зелёными
pytest test_couriers.py -v
